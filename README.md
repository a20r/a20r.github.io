# a20r.github.io

Personal site for Alex Wallar — [a20r.github.io](https://a20r.github.io).

Plain HTML and CSS in a single `index.html`, no build step. The Fraunces typeface
is self-hosted under the SIL Open Font License (see `fonts/OFL.txt`).

- Pushes to `main` deploy via GitHub Pages (`.github/workflows/deploy.yml`).
- Pull requests get a preview at `https://a20r.github.io/previews/pr-<number>/`.
